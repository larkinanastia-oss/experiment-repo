🎄 Адвент-квест: помощник для родителей

Заполните ответы и подсказки для одного ребёнка и нажмите «Создать файл». Получится daria.json или seva.json, в котором ответы и подсказки спрятаны: в коде страницы их не видно. Эта страница ничего никуда не отправляет — всё считается в браузере.

Открыть готовый файл

Чтобы изменить уже созданный файл: выберите его и введите пароль родителя.

Ребёнок

Задания

В каждом дне до 5 заданий; пустые задания в конце не учитываются. Текст задания ребёнок увидит в приложении (следующее задание открывается только после правильного ответа). Несколько вариантов ответа — через запятую, например 5, пять. Регистр, лишние пробелы, точка в конце и «ё/е» не важны; «07» = «7». Ответы — только числа или русские слова. Подсказка ведёт к месту, где спрятано следующее задание; если задания не прячутся отдельно, оставьте её пустой.

Пароль родителя

Нужен, чтобы в режиме родителя (?parent=1) увидеть ответы и перейти к любому заданию, и чтобы потом снова открыть файл здесь. Выберите такой, который дети не угадают. Забудете — придётся заполнить заново.

Черновик — это обычный файл с ответами. Храните его у себя и не загружайте в репозиторий.

Готово

Как загрузить на GitHub: откройте репозиторий → папка advent → нужный файл (например, daria.json) → значок карандаша → выделите всё и вставьте скопированный текст → Commit changes. Или Add file → Upload files и перетащите скачанный файл. Через минуту-две страница обновится.
